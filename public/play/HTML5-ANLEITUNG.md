# Gameboy Browser-Version

Browser-Link:
https://nxn7gmcgmt-byte.github.io/SpaceRocks/

## Spielen

1. Link im Browser öffnen.
2. Einmal ins Spiel klicken, damit Audio und Eingabe freigeschaltet werden.
3. Mit deinem Konto anmelden.
4. SpaceRocks oder ein anderes Spiel im Selector starten.

## Empfohlen

- Desktop: Chrome oder Edge
- Android: Chrome
- iPhone/iPad: Safari kann funktionieren, Audio/Vollbild sind dort aber strenger eingeschränkt.

## Mobile Steuerung

Die Touch-Steuerung wird im Browser automatisch aktiviert, wenn das Spiel auf einem mobilen Browser oder sehr kleinem Bildschirm läuft.

## Speichern

Browser-Saves liegen im Speicher des Browsers. Wenn Browserdaten/Sitedaten gelöscht werden, können lokale Browser-Saves verloren gehen. Account-Daten laufen weiterhin über den Online-Account.

## Update-System

Der Launcher/Boot-Check erkennt jetzt auch die Plattform `web`. Wenn ein Web-Update verfügbar ist, wird der Browser-Spiel-Link als Update-Ziel verwendet.

## Build-Hinweis

Auf diesem PC fehlt im installierten GameMaker-LTS-Runtime-Paket das offizielle HTML5-Modul. Deshalb wurde diese Browser-Version aus dem vorhandenen GX/WebAssembly-Runner gebaut und für normale Browser vorbereitet.
